Recursos

Tudo o que você precisa para conversar com IA

Uma experiência de chat completa, com ferramentas poderosas e integrações nativas.

Chat com streaming

Respostas em tempo real via streaming push-based sobre IPC, com renderização em Markdown, realce de sintaxe e suporte a matemática (KaTeX).

Suporte a imagens

Envie imagens e converse com modelos de visão. O NeoChat detecta automaticamente a capacidade de visão dos modelos Llama 4 e afins.

Servidores MCP

Conecte servidores MCP locais (stdio) e remotos (HTTP) para dar aos modelos acesso a ferramentas e dados externos via function calling.

Conectores Google

Integre Gmail, Google Calendar e Drive com OAuth. Conecte sua conta e permita que a IA acesse e processe seus dados com aprovação.

Ferramentas embutidas

Interpretador de código e busca na web integrados, ativáveis por modelo, para ampliar as capacidades de raciocínio e resposta.

Modelos personalizáveis

Configure temperatura, top-p, esforço de raciocínio e prompt de sistema. Adicione modelos customizados e ajuste a base da API.

Captura de contexto

Atalho global (Ctrl+G / Cmd+G) e protocolo groq:// para capturar contexto de qualquer lugar e enviar direto para o chat.

Tema claro/escuro

Interface com tema claro, escuro ou automático, suporte a múltiplos idiomas e janela popup opcional para acesso rápido.

Diferenciais

Por que escolher o NeoChat Desktop?

Rápido, privado e extensível — pensado para quem leva IA a sério.

01

Velocidade com Groq

Aproveite a inferência ultrarrápida da Groq API com cache de modelos e detecção automática de capacidades por heurística de nome.

02

Privacidade local

Servidores MCP rodam localmente via stdio, com scripts por plataforma. Suas chaves ficam no seu computador — nunca enviadas para servidores nossos.

03

Multiplataforma real

Binários nativos para Windows (NSIS/portable), macOS (DMG/ZIP) e Linux (AppImage/deb/rpm). Testado em todas as plataformas.

04

Extensível

Adicione modelos customizados, defina a base da API, conecte servidores MCP remotos e amplie as capacidades sem limites.

FAQ

Perguntas frequentes

Preciso de uma chave de API da Groq?

Sim. Obtenha sua chave gratuitamente em console.groq.com e adicione-a nas Configurações do app. Você também pode defini-la via variável de ambiente GROQ_API_KEY.

O app é gratuito?

Sim, o NeoChat Desktop é de código aberto e gratuito. Você só precisa de uma chave de API da Groq para usar os modelos de IA.

No macOS aparece um aviso de segurança. O que faço?

Execute o comando abaixo no Terminal e abra o app novamente:
xattr -c /Applications/Neochat\ Desktop.app

O que são servidores MCP?

MCP (Model Context Protocol) permite que os modelos usem ferramentas externas e acessem dados — bancos de dados, APIs, arquivos locais e mais. O NeoChat suporta servidores locais (via stdio) e remotos (via HTTP).

Como funcionam os conectores do Google?

Você conecta sua conta do Google via OAuth para permitir que a IA acesse Gmail, Calendar e Drive. Cada ação pode exigir sua aprovação, controlada nas configurações.
