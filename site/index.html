FAQ

Perguntas Frequentes

Tire suas dúvidas sobre provedores, funcionamento local, chaves de API e privacidade.

Quais provedores e modelos de IA posso usar?

O NeoChat Desktop é independente e universal. Você pode usar:

  • Modelos Locais: Conexão direta com Ollama, LM Studio, vLLM ou LocalAI (Llama, DeepSeek, Qwen, Mistral, etc.) sem custo e offline.
  • APIs Remotas: OpenAI (GPT-4o, o1, o3-mini), Anthropic (Claude 3.7), Groq (inferência ultra-rápida LPU), DeepSeek, OpenRouter, Together AI e qualquer endpoint compatível com o padrão OpenAI.
Posso usar o aplicativo 100% gratuito e offline?

Sim! Ao utilizar provedores locais como o Ollama ou LM Studio, todo o processamento de IA, indexação RAG e ferramentas MCP roda exclusivamente no hardware do seu computador, sem necessidade de chaves de API pagas ou conexão contínua com a internet.

Como funciona o Fallback Automático entre provedores?

Nas configurações do app, você pode definir uma ordem de prioridade. Se o seu provedor principal (por exemplo, uma API em nuvem) sofrer indisponibilidade ou limite de requisições, o NeoChat migra a conversa de forma transparente para o provedor reserva (como seu modelo local ou outra API).

Como funciona o Push-to-Talk por voz?

Basta segurar o atalho Ctrl+Alt em qualquer momento para falar e soltar para transcrever instantaneamente para o chat. O app também inclui sintetizador de voz (TTS) configurável para leitura de respostas.

Como meus documentos e chaves são protegidos?

Chaves de API e segredos OAuth são gravados de forma criptografada usando o SafeStorage nativo do seu sistema operacional (DPAPI no Windows, Keychain no macOS, Secret Service no Linux). No RAG local, seus arquivos são processados e armazenados localmente, sem envio a terceiros.

No macOS aparece um aviso de segurança do Gatekeeper. Como resolver?

Como o app é distribuído de forma independente, execute o comando abaixo uma única vez no Terminal do macOS:

xattr -c /Applications/Neochat\ Desktop.app
